# PixelMaker Stage 1 (Draw) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** An installable, offline web app where you can draw a single-frame pixel sprite on a phone with pencil, eraser, fill and eyedropper, pick colours from palettes, undo/redo, have it autosaved, and export a PNG.

**Architecture:** A UI-free `core` (sprite model, pixel operations, history) and a pure `editor` layer (viewport math, gesture recognizer, `Editor` state object) are unit-tested with Vitest. A thin Preact UI renders `Editor` state and feeds it pointer events; the sprite is composited 1:1 to an offscreen canvas and scaled to screen with smoothing off. The sprite model already has layers, frames and tags so stage 2 adds UI, not a rewrite.

**Tech Stack:** TypeScript, Vite, Preact, Vitest (+ `fake-indexeddb`), Playwright, `vite-plugin-pwa`, GitHub Actions + Pages.

**Spec:** `docs/superpowers/specs/2026-11-24-pixelmaker-design.md`

## Global Constraints

- Target: current Chrome on Android. Static files only, served under `/PixelMaker/` (Vite `base: '/PixelMaker/'`). No server, no origin-specific code.
- Canvas size 1×1 to 512×512; new-sprite presets 16, 32, 48, 64, 128.
- Pixels never smoothed at any zoom (`imageSmoothingEnabled = false`, CSS `image-rendering: pixelated`).
- All controls at least 44 px; bottom sheets, not full-screen takeovers; portrait designed first; dark theme.
- Canvas element has `touch-action: none`; page has `overscroll-behavior: none` and respects `env(safe-area-inset-*)`.
- `src/core` and `src/editor` import nothing from `src/ui`, the DOM, or Preact.
- Undo depth 100. Autosave debounce 500 ms.
- Gesture thresholds live only in `GESTURE_DEFAULTS` in `src/editor/gestures.ts`.
- Every interactive element the e2e tests touch has the `data-testid` named in this plan.
- Commit after each task; commit messages end with the session attribution trailer.

## Review Focus

1. A second finger landing mid-stroke: the partial stroke is rolled back, nothing lands on the undo stack (Task 4, Task 5 tests).
2. Strokes that start or travel outside the canvas: clipped, no throw, no undo entry if nothing changed (Task 2, Task 5 tests).
3. Fill with the colour already there, and fill of a blank 512×512: no-op / completes without recursion or hang (Task 2 tests).
4. `pointercancel` mid-stroke (system gesture, incoming call): stroke rolled back, editor still usable (Task 4, Task 5 tests).
5. IndexedDB unavailable or throwing (private mode, quota): app still opens and draws, a "not saving" notice shows (Task 8 test).

```ts
// viewport.ts — screen = sprite * zoom + pan, in CSS px relative to the canvas element
export interface Viewport { zoom: number; panX: number; panY: number }
export const MIN_ZOOM = 1, MAX_ZOOM = 64, GRID_ABOVE_ZOOM = 8, FIT_MARGIN = 16;
export function screenToSprite(v: Viewport, sx: number, sy: number): { x: number; y: number }; // floored
export function zoomAt(v: Viewport, factor: number, sx: number, sy: number): Viewport; // clamped; point under (sx,sy) stays put
export function panBy(v: Viewport, dx: number, dy: number): Viewport;
export function snapZoom(v: Viewport, sx: number, sy: number): Viewport; // zoom → nearest integer, anchored
export function fit(spriteW: number, spriteH: number, viewW: number, viewH: number): Viewport; // largest integer zoom fitting inside the margin (min 1), centred, pan rounded

// gestures.ts
export type GestureEvent =
  | { type: 'strokeStart' | 'strokeMove'; x: number; y: number }
  | { type: 'strokeEnd' } | { type: 'strokeCancel' }
  | { type: 'transform'; dx: number; dy: number; scale: number; cx: number; cy: number } // increment since last event; c = current midpoint
  | { type: 'transformEnd'; cx: number; cy: number }
  | { type: 'tap2' } | { type: 'tap3' }
  | { type: 'longPress'; x: number; y: number };
export const GESTURE_DEFAULTS = { tapMaxMs: 250, tapMaxMovePx: 10, longPressMs: 500, longPressMaxMovePx: 8 };
export interface Timer { set(fn: () => void, ms: number): unknown; clear(handle: unknown): void }
export class GestureRecognizer {
  constructor(emit: (e: GestureEvent) => void, opts?: typeof GESTURE_DEFAULTS, timer?: Timer);
  down(id: number, x: number, y: number, t: number): void;
  move(id: number, x: number, y: number, t: number): void;
  up(id: number, t: number): void;
  cancel(id: number): void;
}
```

Gesture rules:
- First pointer down emits `strokeStart` at once (no draw delay) and arms the long-press timer.
- Moving more than `longPressMaxMovePx` from the down point disarms long-press. If the timer fires: `strokeCancel`, then `longPress` at the down point; later moves/up of that pointer emit nothing.
- A second pointer down during a stroke emits `strokeCancel` and enters multi-touch. A second pointer after long-press fired just enters multi-touch.
- In multi-touch, `transform` events are emitted only once any pointer has moved more than `tapMaxMovePx` from its down point; they use the first two pointers. When the last pointer lifts: if no transform was emitted and it is within `tapMaxMs` of the first down, emit `tap2` (max 2 pointers seen) or `tap3` (3 seen); otherwise emit `transformEnd`.
- After multi-touch, remaining fingers never resume a stroke; a new stroke needs all pointers up first.
- `cancel` of the stroke pointer emits `strokeCancel`; `cancel` in multi-touch ends it as `transformEnd` (no tap).
- Pointers beyond the third are ignored.

```ts
// palettes.ts
export interface Palette { id: string; name: string; colors: Color[] }
export const PALETTES: Palette[];   // ids: 'pico8' (16), 'db16' (16), 'db32' (32), 'endesga32' (32), 'sweetie16' (16), 'gameboy' (4)
export const DEFAULT_PALETTE_ID = 'pico8';

// editor.ts
export type ToolId = 'pencil' | 'eraser' | 'fill' | 'eyedropper';
export interface EditorState {
  sprite: Sprite; layer: number; frame: number;
  tool: ToolId; fg: Color; bg: Color;
  brushSize: number;                 // 1–8
  brushShape: 'square' | 'round';
  fillContiguous: boolean;
  viewport: Viewport;
  revision: number;                  // increments whenever sprite pixels/structure change
}
export class Editor {
  constructor(sprite: Sprite);
  readonly state: EditorState;       // mutated in place; listeners are told when
  readonly history: History;
  subscribe(fn: () => void): () => void;
  setTool(t: ToolId): void; setFg(c: Color): void; setBg(c: Color): void; swapColors(): void;
  setBrushSize(n: number): void;     // clamped 1–8
  setBrushShape(s: 'square' | 'round'): void; setFillContiguous(b: boolean): void;
  setViewport(v: Viewport): void;
  strokeStart(x: number, y: number): void;  // sprite coordinates
  strokeMove(x: number, y: number): void;
  strokeEnd(): void; strokeCancel(): void;
  pick(x: number, y: number): boolean;      // eyedropper from the composited frame; false and no change on a fully transparent pixel
  undo(): void; redo(): void;
  loadSprite(s: Sprite): void;              // replaces sprite, clears history, layer/frame = 0
  setPalette(colors: Color[]): void; addPaletteColor(c: Color): void; removePaletteColor(i: number): void; replacePaletteColor(i: number, c: Color): void;
}
```

Behaviour:
- Defaults: tool `pencil`, `fg` = first palette colour or `0x000000ff`, `bg` = `0xffffffff`, brush 1, square, contiguous fill.
- Pencil/eraser: `strokeStart` snapshots the active cel; start and each move stamp along `linePoints` from the previous point; eraser stamps `TRANSPARENT`. `strokeEnd` pushes one `pixelPatch` covering the union dirty rect, or nothing if the dirty rect is null or the pixels are unchanged. `strokeCancel` restores the snapshot and pushes nothing.
- Fill: acts on `strokeStart` only; one history entry; none when `floodFill` returns null.
- Eyedropper: `strokeStart` and `strokeMove` call `pick`; never touches history.
- A locked or invisible active layer ignores drawing tools.
- Palette edits and tool/colour changes are not undoable. `addPaletteColor` ignores a colour already present.
- `revision` increments on every pixel change including each stroke move, undo, redo, cancel-with-changes and `loadSprite`.
